# データベースエラー対処ガイド

このドキュメントでは、アプリで発生する可能性のあるデータベースエラーと対処方法を説明します。

## 🔄 スキーマキャッシュエラー（コールドスタート）

### エラーメッセージ
```
Database query failed: Could not query the database for the schema cache. Retrying.
```

### 原因
Supabaseの無料プランでは、一定期間（通常1時間以上）データベースへのアクセスがないと、データベースが自動的にスリープ状態になります。初回アクセス時にデータベースが起動するまで、このエラーが発生します。

### 特徴
- ⏳ **初回アクセス時に発生** - 長時間アクセスがなかった後の最初のリクエスト
- 🔄 **一時的なエラー** - データベースが起動すれば自動的に解決
- ⏱️ **起動時間** - 通常30秒〜1分程度（最大2分）

### 自動対処
サーバー側で以下の対処を自動的に行います：

1. **リトライ回数**: 最大5回
2. **待機時間**: 指数バックオフ（3秒 → 6秒 → 12秒 → 24秒 → 48秒）
3. **ログ出力**: 詳細なリトライ情報をコンソールに出力

### ユーザー側の対処方法

#### 方法1: 待機してリトライ（推奨）
1. エラーが表示されたら、**1〜2分待つ**
2. ページを**リロード**するか、「接続テストを開始」ボタンをクリック
3. データベースが起動していれば、正常に動作するはずです

#### 方法2: Supabaseダッシュボードで確認
プロジェクトの状態を確認します：

1. [Supabaseダッシュボード](https://supabase.com/dashboard/project/xhscnrprqokggtcbhwra)にアクセス
2. プロジェクトの状態を確認
   - ✅ **Active**: 正常
   - ⏸️ **Paused**: 一時停止中（Resumeボタンをクリック）
   - 🔴 **Error**: エラー状態（Supabaseサポートに連絡）

### 診断ツール

#### サーバー接続テスト
```
/?test=connection-test
```
このページで以下を確認できます：
- サーバーへの接続状況
- データベースのレスポンス時間
- エラーの詳細情報

## 🚫 Error 521: Web server is down

### エラーメッセージ
```
Database server is unavailable (Error 521). Please check Supabase dashboard.
```

### 原因
Supabaseのデータベースサーバーが完全にダウンしているか、ネットワーク接続に問題があります。

### 対処方法

1. **Supabaseステータスページを確認**
   - https://status.supabase.com/
   - メンテナンスや障害情報を確認

2. **プロジェクトの状態を確認**
   - Supabaseダッシュボードで、プロジェクトが一時停止していないか確認
   - 無料プランの場合、一定期間使用がないと自動的に一時停止されます

3. **環境変数を確認**
   - `SUPABASE_URL` が正しく設定されているか
   - `SUPABASE_SERVICE_ROLE_KEY` が正しく設定されているか

## 💡 ベストプラクティス

### 無料プランを使用している場合

1. **定期的にアクセス**
   - データベースがスリープしないよう、定期的にアクセスすることを推奨
   - 少なくとも1時間に1回はアクセスすると良い

2. **初回アクセスは余裕を持って**
   - 初回アクセス時は1〜2分程度かかることを想定
   - 重要な作業の直前ではなく、事前にアクセスしておく

3. **有料プランへのアップグレード検討**
   - 本番環境では、Pro プラン以上の使用を推奨
   - データベースが常時起動状態を維持

### エラーログの確認

ブラウザのコンソール（F12）を開いて、詳細なエラーログを確認できます：

```javascript
// サーバー側のログ
✅ Creating Supabase client for URL: https://...
⚠️ Schema cache error detected. This is usually temporary during database cold start.
⚠️ Retry 1/5 for offset 0 (waiting 3000ms): Database query failed: ...
✅ Successfully retrieved batch at offset 0
```

## 🔧 トラブルシューティング

### エラーが継続する場合

1. **ブラウザのキャッシュをクリア**
2. **別のブラウザで試す**
3. **ネットワーク接続を確認**
4. **Supabaseダッシュボードでログを確認**

### サポートが必要な場合

以下の情報を準備してください：
- エラーメッセージの全文
- ブラウザのコンソールログ（F12）
- 発生した日時
- 再現手順
